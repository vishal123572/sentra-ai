# Two-minute demonstration walkthrough

Run `python3 run.py --demo`, sign in before recording, and select Latest per entity. All shown records are synthetic.

| Time | Screen and action | Suggested narration |
|---|---|---|
| 0:00-0:15 | Overview: open Atlas Grid's assessment. | SAT-SA analyses periodic SOC records to focus human supervisory review. Attention labels and the calculated index are distinct. |
| 0:15-0:35 | Show execution-gap/negative-space panels, peer table and index contributions. | These findings identify unsupported execution. Each peer rate has an eligible population and a comparable same-period cohort. Missing inputs are excluded from the index, not scored as healthy. |
| 0:35-0:55 | Click Review 8 selected records; inspect a selection breakdown. | The sample represents available detector types, prioritises severity and overlapping signals, and merges duplicate cases. Its points are a transparent review heuristic. |
| 0:55-1:15 | Open a record, then Review finding group → Evidence Investigation. | The affected-record table, policy expectation, peer baseline, rule version and source presence explain why this group was flagged. Open full evidence for the timeline and source hash. |
| 1:15-1:30 | Click Needs information; save a written reason. | The examiner decides. Input-file presence does not establish export completeness or policy compliance. History preserves each decision. |
| 1:30-1:45 | Open Check what the detectors missed; inspect a case and save Needs more information. | Independent cases exclude all direct and linked stored flags. We document concerns the detectors may have missed, without automatically confirming them. |
| 1:45-1:50 | Open Northstar Power: coverage gap and activity context. | Coverage uses explicit inventory expectations. Low activity is separate context, never proof of missing telemetry. |
| 1:50-2:00 | Export assessment HTML; show offline status. | The report carries index rationale, peer context, recommended IDs and examiner decisions. All processing is local and offline. |

Record using your operating system's screen recorder. Keep genuine SOC records out of the video. This package contains the real application and walkthrough, not a fabricated recording. For a technical follow-up, open Atlas's closure outlier and SLA-edge finding: both expose measured detector context and conservative examiner checks.
